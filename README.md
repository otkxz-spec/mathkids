# Math Kids v3

Static installable web app for math practice.

## New in v3
- 1-, 2-, or 3-digit difficulty for addition and subtraction.
- Both operands use the selected digit count. Examples: 7 + 4, 34 + 58, 276 + 481.
- Subtraction reorders operands so answers are never negative.
- Progress records addition and subtraction accuracy separately by digit count.

## Deploy with GitHub Pages
1. Upload all files in this folder to the repository root.
2. Repository Settings > Pages > Deploy from a branch.
3. Choose `main` and `/ (root)`.
4. Open `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`.

Progress and profiles are stored locally in the browser. Existing v2 profiles are migrated automatically and default to 1-digit addition/subtraction.
